<h1>
    Project Breakdown
</h1>

<ul>
    <li> <h3>Project Breakdown :</h3>
        <p>
            MyHealthOnline is set to fit in the ever growing fitness and health landscape, but creating a place that neatly and efficiently stores all your health data. Major features all take inspiration from the largest players in the current space and combine them neatly into one app. This prevents you from installing seperate services for all things health.
        </p>
    <li> <h3>Purpose : </h3>
        <p>
            This project comes from the idea and the practice where a lot of fitness apps serve 1 purpose well, but implemented other features in a lackluster way. I personally have 3 different apps for tracking calories, weight, workouts, and finding stores to purchase food for. I believe this drives people away from pursuing fitness since all decent features of these apps are hidden behind a paywall, and all the other features are severly lacking good implementation.
        </p>
    </li>
    <li> <h3>How It Works: </h3>
        <p>
            MyHealthOnline utilizes free public apis to pull hundreds of thousands of branded food items thanks to the USDA public database. This allows for food searching, and logging nutrients and calories for all types of food items you may eat. The workout tracker utilizes the WGER public API to pull hundreds of exercises with in depth descriptions. Alongside this you can create workouts and add your own custom exercises and weight and reps used on each exercise/
        </p>
    </li>
    <li> <h3>My Personal Why : </h3>
        <p style="text-indent: 40px">
            I created this project for a few purposes, firstly I created it as
            a way to learn and work with Express.js and React prior to graduating from college. Whenever I work on a personal project, even if it's just for adding to my portfolio, I try to create something I personally would use. Hence I built an app I have been wanting for a long time over the course of my fitness journey.
        </p>
    <li> <h3>What Does The Future Look like?</h3>
        <p style="text-indent: 40px">
            This project has effectively served the purpose I set out for it, to teach me how React and Express work, and really put into practice coding theory I have spent the last few years learning, such as logging, testing, CI/CD, AWS, cloud services, Docker, etc. So realistically I could call it a day here, but like my other full-stack project I dont find that good enough. I already feel like I would use this app over the 3 others I use to achieve the same thing, but I don't want it to be marginally better, but significantly better. As I prepare for a hopeful internship or junior position my commits and time spent on this project may slow (probably not this is project is a passion project as much as it is a personal portfolio item), but I will continue to improve and add features to it. I hope to continuosly come back to this project over a long period of time constantly improving, and adding to it. I hope over the next month or two I can implement the features I would see as making this app significantly better than the alternatives I currently use.
</ul>
